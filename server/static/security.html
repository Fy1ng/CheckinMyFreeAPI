LOGIN AND SECURITY

登录与安全

先绑定并验证密钥, 再选择适合你的登录模式.

登录模式

密码版保留管理密码登录. Passkey 版关闭公网密码登录, 使用设备验证或安全密钥. 两种模式保留相同的账户、任务与历史数据.

已绑定 Passkey

新密钥需要成功完成一次验证后才能启用 Passkey 版. 启用时会再次验证你的密钥.

添加 Passkey

使用 Windows Hello、手机或硬件安全密钥. 建议绑定另一把备用密钥, 以便设备丢失时登录.

确认当前身份

密码版中的添加和删除操作需要重新验证管理密码. Passkey 版使用新的设备验证, 公网不能通过密码绕过.

设备丢失或地址变化

Passkey 绑定注册时的管理入口. 地址变化或没有可用密钥时, 使用 SSH 恢复工具切换登录模式. 公网不会自动回退到密码登录. Passkey 版不能删除最后一把当前入口已验证的密钥.

NewAPI Check-in服务器保存公钥, 不读取你的设备私钥.
